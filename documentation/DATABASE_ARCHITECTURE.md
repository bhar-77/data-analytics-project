# TravelLens AI – Database Architecture & SQL Analytics Specification

## Relational Database Engine
- **RDBMS**: MySQL 8.x Community Server
- **Database Name**: `travellens_db`
- **Normalization Standard**: Third Normal Form (3NF)
- **Character Set**: `utf8mb4`
- **Collation**: `utf8mb4_unicode_ci`

---

## Entity Relationship Schema (12 Tables)

### 1. Master Dimensions
- `users`: User authentication, role-based access control, hashed credentials.
- `cities`: Indian metro hubs (Bengaluru, Delhi, Mumbai, Chennai, Hyderabad, Kolkata, Pune, Goa) with IATA code, latitude, longitude, tier, and key attractions.
- `airlines`: Domestic carrier dimension (IndiGo, Air India, Vistara, SpiceJet, Air India Express, Akasa Air) with fleet size, rating, and IATA codes.

### 2. Transactional Travel Tables
- `flights`: Flight schedules, stops (0, 1), class (Economy, Business), base price, surge/current price, duration, days left, seats left. Foreign keys to `airlines` and `cities`.
- `hotels`: Hotel listings across metro hubs, star ratings (5-star, 4-star, 3-star), user rating, nightly tariff, amenities. Foreign key to `cities`.
- `trains`: Indian Railways (IRCTC) schedules, Vande Bharat Express, Rajdhani Express, Shatabdi, travel classes (1A, 2A, 3A, CC, EC, SL), fares, running days.
- `buses`: Intercity luxury coach services (Volvo Multi-Axle AC Sleeper, Scania Semi-Sleeper, BharatBenz AC), operators (KSRTC, Orange, SRS, VRL, Zingbus), ticket prices.

### 3. Analytics & Logging Tables
- `price_history`: Multi-month time-series snapshots with seasonal markers, weekend flags, surge multipliers.
- `predictions`: Persistent machine learning predictions generated by the Random Forest model, logged with confidence scores and model version.
- `search_history`: Search queries submitted by users across all travel categories.
- `uploaded_datasets`: Metadata catalog of raw and processed CSV datasets.
- `data_cleaning_logs`: Complete ETL audit trail detailing nulls imputed, duplicates removed, and IQR price deviations detected.

---

## Analytical Views
1. `v_airline_performance`: Carrier flight counts, average fare, minimum fare, peak fare, average duration.
2. `v_route_price_summary`: Route-by-route flight counts, average fares, minimum fares.
3. `v_monthly_category_trends`: Multi-month cross-modal time series for seasonal trend reporting.

---

## Demonstrated SQL Capabilities
- **Window Functions**: `ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)`, `LAG(price, 1) OVER (...)`, `AVG() OVER (ROWS BETWEEN 3 PRECEDING AND 3 FOLLOWING)`.
- **Common Table Expressions (CTEs)**: Multi-stage CTEs computing cross-modal price premiums.
- **Correlated Subqueries**: Identifying flight fares priced below route averages.
- **Joins**: INNER JOIN, LEFT JOIN, CROSS JOIN.
- **Aggregations & Filtering**: `GROUP BY`, `HAVING COUNT(*) >= 5`, `ORDER BY`.
